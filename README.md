# eTailEdge

A full-stack clothing eCommerce platform built with Next.js, MySQL, Knex.js, Redux Toolkit, and modern web technologies. The platform provides a seamless shopping experience for customers along with powerful product and order management capabilities.

## Live Demo

🔗 https://etailedge.netlify.app

* User Registration & Authentication
* Secure Login System

## Installation

### Clone Repository

```bash
git clone https://github.com/chhaya742/eTailEdge.git
```

### Install Dependencies

```bash
npm install
```

### Configure Environment Variables

Create a `.env.local` file and add:

```env
DB_CONNECTION=
DB_HOST=
DB_PORT=
DB_NAME=
DB_USER=
DB_PASSWORD=

JWT_SECRET=
DATABASE_URL=
```

### Start Development Server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
